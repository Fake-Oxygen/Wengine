# Using WEngine

You run simulations and read what they produced — no engine source
reading required. This portal takes you from a clean machine to a
running simulation with inspectable output, then through each front end
and output format.

## Guides

- **Getting started** — prerequisites, build, first run.
- **CLI commands** — every command family and what each is for.
- **Outputs** — output formats and exit codes.
- **Graphical app** — panels and workflows.
- **Troubleshooting** — diagnosing failures from documented behavior.
